Splat Viewer

Gaussian splats in your browser and on every device

An open-source viewer built on the Godot engine. It opens .ply, .splat and .spz files and streams OGC 3D Tiles splat scenes. Early preview.

Install notes

  • Android: allow installs from unknown sources. The APK has a debug signature.
  • Windows: unsigned, so SmartScreen warns you. Choose "More info → Run anyway".
  • macOS: not notarized. Right-click the app → Open, or run xattr -dr com.apple.quarantine "Godot Splat Viewer.app".
  • iOS: unsigned. Sideload with a free Apple ID through AltStore or Sideloadly (re-sign every 7 days).
