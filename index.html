Godot Splat Viewer

A Gaussian splat viewer built with the open-source Godot engine. It views single splat files (.ply, .splat, .spz) and streams tiled splats in the OGC 3D Tiles format. Early preview.

Install notes

  • Android: allow installs from unknown sources. The APK has a debug signature.
  • Windows: unsigned, so SmartScreen warns you. Choose "More info → Run anyway".
  • macOS: unsigned and not notarized. Right-click the app → Open, or run xattr -dr com.apple.quarantine "Godot Splat Viewer.app".
  • iOS: unsigned. Sideload it with a free Apple ID through AltStore or Sideloadly (it has to be re-signed every 7 days), or build from the Xcode project.
